# OS-Hospital-ER-Simulation
Hospital Emergency Room Simulation

A Java-based Operating Systems project that simulates a hospital emergency room using the Producer–Consumer problem, Bounded Buffer, and Semaphores.

Course

Operating Systems — Assignment 1

Technologies

* Java
* Multithreading
* Semaphores
* Producer–Consumer Problem
* Bounded Buffer

Project Structure

The project is organized into separate classes, with each class responsible for a specific part of the simulation.
